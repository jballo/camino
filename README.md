# CAMINO

Generate guided tours of unfamiliar codebases. Paste a GitHub URL, pick a topic ("authentication flow", "request lifecycle"), and get a structured walkthrough with code snippets, file references, and explanations of why the code exists the way it does.

Built for new hires, OSS contributors, and anyone who's ever opened a repo and thought "where do I even start?"
